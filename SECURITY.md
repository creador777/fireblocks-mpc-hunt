# Security and disclosure

This repository contains testing infrastructure, not undisclosed findings.

Do not open public issues containing:

- fuzzer inputs, corpus files, crashes or proof-of-concept material;
- raw sanitizer or libFuzzer logs;
- Base64, hexadecimal or ASCII representations of an input;
- private paths, credentials or repository tokens.

Potential findings must be handled through the applicable authorized disclosure
channel. Public workflow output is metadata-only and encrypted artifacts require
the campaign owner's offline private key.
